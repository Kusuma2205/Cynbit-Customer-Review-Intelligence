
# AI-Powered Customer Review Intelligence System

## Project Overview
An AI/ML proof of concept for analyzing customer reviews.

## Features
- Sentiment classification
- Customer complaint detection
- Suggested customer responses
- Review analysis dashboard

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit

## Dataset
Public sentiment dataset from Hugging Face.

## Purpose
Developed as an independent proof of concept for the Cynbit AI/ML Engineer Intern assessment.
